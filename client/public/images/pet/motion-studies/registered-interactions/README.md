# 互動與玩耍：拆格素材

這裡保留原始姿勢的透明像素並整理成單格 PNG 與 4 × 2 atlas。檔名尾碼按原圖由左至右、由上至下排序。各 JSON 記錄畫布尺寸與影格檔名。素材使用同一比例、輪廓水平置中及底部對齊；非依身體骨架、眼睛或腳掌精確配準。可用於檢視和後續製作，但並非已驗收的流暢動畫。

- `attention`：1–3 是直立注意；4 四足靠近；5 眨眼；6 抬爪；7 歪頭；8 期待。不同姿勢之間有顯著跳變，4 尤其不能直接當作 3 至 5 的流暢過渡；4 的右側鬍鬚在原圖邊緣已有截斷。
- `petting`：1–4 是站坐與摸頭反應；5–7 是露肚與側躺；8 是伏下休息。兩組姿態之間缺少中間影格；不可直接將全部按順序循環當作撫摸動畫，也沒有區分不同觸摸區域的完整反應序列。
- `play`：8 個姿勢是警覺、嗅聞、抬爪、俯身、跳躍、落地、坐起與擺尾的研究。姿態與視角變化大，不能直接視作一套連續動作，特別是第 5 張的腳步離地與位置需在後續配準；鬍鬚附近可能有原圖的透明邊緣碎片。

請以這些影格做動作規劃，新增實際過渡影格並逐格校對後再接入 App。原始圖在上一層目錄，未修改。拆格腳本為 `scripts/prepare-companion-interactions.mjs`；它只搬移已有像素，沒有製造新的動畫影格。
