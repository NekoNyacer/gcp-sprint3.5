# 花栗鼠健走 Agent 第一版

## 使用方式

點花栗鼠 →「幫我安排」→ 輸入「20 分鐘，順便補水」→ 檢視方案 →「套用路線」→ 在首頁沿用既有確認出發流程。

「對話」保留一般聊天；「幫我安排」開啟規劃對話，同一輪互動可用「調整需求」修改條件。尚未提供時間時會詢問。已有目的地、進行中的路線或培育視窗時，先完成／取消原流程再安排，避免覆蓋玩家的工作。

## 資料與執行邊界

- `CompanionAgentService` 讀取現有 LocationStore、ProgressStore、公開 CMS 站點資料。
- 最近最多三棵已種植、今日可造訪的樹，每棵產生直達與可選的遊戲補水方案，最多六條候選。
- 路線由既有 Mapbox Directions 服務計算。CMS 模式選取距原路線一公里內最近的有效水資源商家；非 CMS 模式沿用 Demo 補給站。
- 天氣重用種樹視窗的 `LiveEnvironmentService.weatherAt`（Open-Meteo、五分鐘快取）；失敗顯示無資料，不使用種子天氣冒充即時資訊。
- 只有候選摘要、資源與位置來源傳給 `companionChat`；不傳路線座標、原始 GPS 或完整樹木資料。快照是建議資料，不能授權獎勵或資料庫寫入。
- 後端透過 Vertex AI Gemini Function Calling：讀取玩家狀態 → 依模型理解的分鐘／補水需求篩選候選 → 有符合條件的候選才允許提出方案 → 回覆。最多四次模型請求、八次工具呼叫、共 25 秒模型時限，沿用每小時 30 次的身分配額。
- 由後端工具強制檢查時間上限（向上取整至分鐘）與遊戲水資源條件；模型只能選取已篩選的候選 ID，不能新增任意操作或座標。
- 使用者確認前不修改 WalkSessionStore。確認時再次驗證帳號、CMS 版本、五分鐘有效期、起點移動不超過 50 公尺、樹木與站點狀態，以及原有規劃是否仍空白。
- 導頁成功後，將已查得的路線、目的地與補給站套入既有規劃 Store；已在首頁時不重複導頁。保留首頁的明確出發確認與打卡規則。
- 規劃只在 App 記憶體內，不新增 Firestore 計畫、持久偏好或背景排程。後端僅保留既有配額計數，不儲存對話／路線；關閉互動會丟棄未完成回應。

## 展示範圍

時間為單程步行估計，不含停留與回程。補水為遊戲水資源，不保證實體飲水或營業狀態。UI 明確標示 Demo 起點或目前定位。限於附近候選，不宣稱搜尋所有地區；不自動打卡、澆水、發獎、兌換或取代現有導航驗證。

## 互動與動畫

保留既有奔跑素材、48px 圓形 FAB、隱藏原生編輯器、IME 防誤送、Escape／點外關閉及 reduced-motion 行為。使用原有待機／打招呼呈現等待／回覆；未引用 `motion-studies` 未完成素材。

延續橄欖綠 `#425d22`、橘色 `#ee6a17`、奶油色氣泡、既有字體與 14px 氣泡圓角。第四顆 FAB 使選單寬度調整為 264px；方案氣泡不透明，依可見高度捲動，最高 360px。「套用路線」至少 44px 高。長方案在短螢幕須捲動閱讀。

已由獨立 Impeccable finish reviewer 與 documenter 檢查 320×568、390×844、1024×768 的正常／捲動畫面；沒有新增全域設計系統或 raster 圖片。

後續已依使用者同意整合 `animations/` 的動作素材與卡片跳躍；原始 `motion-studies/` 仍獨立保留。最新移動節奏為短促快跑、完全停下觀察再移動：一般快跑 .28–.62 秒、280–420 CSS px/s，起步／煞停各 35ms，跨 tab 進場 .55–.70 秒；跑步 atlas 為 26fps。

撫摸現為從底部滑入的原生 modal dialog，手機全寬、桌面最高 560px 寬。入場 320ms、離場 180ms，減少動態效果時略過位移。草皮重用既有晴天場景的草地前景，保留直接觸摸頭／肚子、鍵盤焦點、Escape／背景關閉及關閉後還原。39 項相關測試與手機／桌面瀏覽器驗證通過；不代表所有姿勢已具完美的動物動作連續性。

依後續提供的參考圖，撫摸視窗再改成接近全高的草地場景：大尺寸角色、頂端可點擊／下拉的把手、浮動回應，沒有固定白色標題列與底部按鈕列。摸頭／摸肚子的替代按鈕仍可透過鍵盤聚焦顯示。新增的近距離 idle 使用既有 breathing-source.png 與 blinking-4-source.png 製成對位圖集，呼吸時每約六秒穿插眨眼，觸摸反應完成後自動回到 idle。對應驗證更新為 40 項測試；此近距離 idle 不改變巡遊角色原本的待機素材。

## 維護與驗證

- Functions：`npm run build`，`npm test -- companion-chat.spec.ts companion-agent-domain.spec.ts`。
- Client：`npm test -- --watch=false --include='src/shared/components/companion/*.spec.ts' --include='src/features/home/home.component.spec.ts' --include='src/shared/stores/walk-session-store.spec.ts'`。
- `scripts/verify-companion.mjs`：實際編譯 App 的離線瀏覽器驗證，外部 Mapbox／Open-Meteo／Gemini 使用明確 fixture。覆蓋多尺寸、鍵盤、捲動操作與真實 Store 套用；不代表所有外部服務已端到端驗收。
- `scripts/verify-companion-agent-live.mjs`：以合成候選摘要測試真實已部署的 Vertex AI 工具呼叫與無可行方案；建立並清除短期匿名 Demo 身分，不寫入計畫或獎勵。
- Firebase CLI 快取登入失效時可使用既有、有效的 gcloud 帳號做單支函式部署。先建置 Functions，再部署 `companionChat`；`functions/.gcloudignore` 排除依賴與本地環境檔，保留 `lib/`。保持原地區、服務帳號與執行環境。不要以失效快取憑證推論整個 GCP 帳號都無效。

第一版不重新發布 Hosting；前端透過本機 Web preview 驗收。

## 後續修正：暫時氣泡與切圖

撫摸氣泡於三秒後淡出，新觸摸會重新顯示；一般花栗鼠回話於五秒後收起，輸入中、處理中、錯誤重試與待確認路線保留。四組近距離圖集預先解碼；切換時保留前一張直到新圖可繪製，再用 180ms 淡接，關閉或新動作會使過期解碼回應失效。42 項相關測試及實際瀏覽器的氣泡消失／再出現檢查通過。

不同圖集的頭身胖瘦仍是素材一致性問題；程式修正不代表已補出解剖連續性。補圖應先統一母版、頭／軀幹／腳掌基準與相機，再補中立姿勢和反應回 idle 的過渡，而非單純增加影格數。

## 2026-10-30：新版素材完整接入

畫圖 session 的兩批新交付已接入。近距離改用 `animations/petting-unified/` 四組共同基準：idle、摸頭、摸肚子與 expression；每組 5×2、10 格、521×549，每組首尾皆與 `neutral.png` 逐像素相同。idle 與表情 6fps，三次 idle 循環後播放表情；觸摸反應 8fps、末格停留 200ms 後回 idle。已移除近距離流程中的舊呼吸／眨眼／反應圖混用。解碼期間顯示共同中性圖，同一中性首尾交接不疊加淡出層；中途打斷才保留短淡接。

其他六組新素材為抓起、懸空、下落落地、跳上、跳下、蜷睡。巡遊花栗鼠可拖曳：8px 門檻區分輕點，400ms 抓起後懸空；保留抓取位置、限制在畫面內，放手後按重力落在下方最近的可站立卡片或 tab，200ms 落地後交回平台系統。拖曳不切換頁籤，放手產生的 click 不會誤開對話；輕點與鍵盤互動保留。跳躍／下落影格依實際軌跡進度播放。新版睡姿含透明且尺寸一致的靜態備援，避免舊睡圖突然放大。

`prepare-companion-unified.mjs` 驗證並複製四組端點；`prepare-companion-drag-animations.mjs` 使用連通輪廓拆格、每組固定比例與共同腳底基準，保留來源及清單。候選替代草圖未當作 runtime 素材。54 項測試與 `verify-companion-new-art.mjs` 的手機／桌面真實滑鼠觸控驗證通過；既有外部服務使用本機 Demo／阻擋 HTTPS 的驗證方式。截圖可確認顯示與尺寸，不能證明所有中間影格自然。原始圖仍有少量毛髮／五官漂移與一處既有鬍鬚裁切；慢速行動網路初次載入亦未驗收。沒有新增後端或 Hosting 發布。

後續依使用者要求，抓起狀態可在左右邊緣帶著花栗鼠切換頁籤。順序為健走→任務→兌換→回憶林→我的；最左／最右停止，不循環。指標進入 16px 邊緣區切換一頁，移回 32px 內側後才重新觸發。自身換頁保留抓取點、指標捕捉及懸空／落地狀態；等待換頁期間放手也能安全落地。其他一般導頁仍取消拖曳，導頁失敗則留在原頁且可繼續拖曳。這取代上段對「拖曳不切換頁籤」的早期限制；自主巡遊仍沿用原本不帶玩家換頁的循環規則。59 項相關測試通過；`verify-companion-drag-tabs.mjs` 亦以實際觸控／滑鼠檢查五個頁籤雙向切換、兩端不循環、停在邊緣不連跳、捕捉不中斷與放手落地。
